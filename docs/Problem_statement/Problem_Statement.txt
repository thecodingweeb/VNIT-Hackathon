PROBLEM STATEMENT:
	Automated Camera Trap Triage and Individual Tiger Movement Intelligence System for Pench Tiger Reserve.
EXPECTED SOLUTION:
	i. Blank image filtering and removal: The system must ingest raw image directories and automatically classify each frame as blank or containing a subject. Blank images must be removed from the working dataset. Deletion must be safe and reversible using a quarantine or staged-delete approach with a confidence threshold. The system must report how many frames were removed and the space and time saved.

ii. Individual tiger identification via stripe pattern, building a persistent database: For every retained image containing a tiger, the system must detect the animal, isolate the flank, and extract the stripe pattern to match against a growing catalogue of known individuals. New individuals must be automatically enrolled with a new identifier. Confident matches should be applied automatically, while ambiguous matches must be surfaced to a human reviewer. The result should be a persistent, queryable database linking each identified individual to every image, station, timestamp, and GPS location where it was captured.

iii. Tiger-wise area occupancy, regenerated on every run: After each processing run, the system must generate for every individual the set of capture locations, a mapped home range estimate, the centroid of its activity, and the estimated area occupied. This must be visualised on a tiger reserve map and exported in a form usable by forest department staff. Territorial overlap between individuals should also be visible.

iv. Deviation and trend alerting: The system must compare each run against the individuals established history and raise alerts for meaningful changes, including range shifts beyond defined thresholds (15–20 sq km in the core and 5 km in the buffer region), first capture at a previously unused station, movement into or toward buffer or village-adjacent stations, and prolonged absence of a previously regular individual. Alerts must distinguish genuine behavioural deviations from survey artefacts and include the detected change, supporting evidence, and a confidence level.
